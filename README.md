# SMART VISION — Система распознавания лиц «свой / чужой»

Прототип (MVP) системы биометрического контроля доступа.
Хакатон SMART VISION, IT.Бирюлево, 19–20 мая 2026.

Сервис получает изображение лица, сравнивает его с базой данных,
рассчитывает процент совпадения и принимает решение о допуске:

- **свой** — доступ разрешён при совпадении выше порога;
- **чужой / unknown** — доступ запрещён;
- **чёрный список** — доступ запрещён независимо от процента совпадения.

Каждое событие записывается в SQL-базу и в текстовый файл-журнал.

---

## Стек

- **Python** — вся логика проекта (≈98%, кроме HTML/CSS веб-страницы).
- **SQLite** — SQL-база данных (группы, лица, признаки, проверки, журнал, настройки).
- **OpenCV (DNN)** — биометрия:
  - **YuNet** — детектор лиц;
  - **SFace** — извлечение 128-мерного эмбеддинга лица.
- Сравнение лиц — по **косинусной близости** эмбеддингов.
- Веб-интерфейс — на стандартной библиотеке Python (`http.server`), без сторонних фреймворков.

## Структура проекта

```
config.py        — пути и константы
schema.sql       — SQL-схема базы данных
database.py      — слой работы с SQLite
face_engine.py   — детекция лица и расчёт эмбеддинга (OpenCV)
service.py       — бизнес-логика: enroll / check / white-black list / журнал
cli.py           — командный интерфейс
webapp.py        — веб-интерфейс (http.server)
seed.py          — загрузка демо-набора лиц
models/          — ONNX-модели YuNet и SFace
faces_data/face/ — тестовые изображения лиц
logs/checks.log  — файл-журнал проверок (создаётся автоматически)
database.db      — база данных (создаётся автоматически)
```

## База данных

| Таблица         | Назначение |
|-----------------|------------|
| `groups`        | группы доступа: Свой (white), Чужой (neutral), Чёрный список (black) |
| `persons`       | лица: имя, группа, статус (active / removed) |
| `face_features` | биометрические признаки — эмбеддинги лиц (BLOB) |
| `checks`        | журнал проверок: дата, файл, лицо, группа, процент, решение, причина |
| `settings`      | настройки: порог совпадения, режим |

## Установка

Требуется Python 3.9+.

```bash
pip install -r requirements.txt
```

Модели уже лежат в папке `models/`. Если их нет — скачайте из OpenCV Zoo:

- [face_detection_yunet_2023mar.onnx](https://github.com/opencv/opencv_zoo/raw/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx)
- [face_recognition_sface_2021dec.onnx](https://github.com/opencv/opencv_zoo/raw/main/models/face_recognition_sface/face_recognition_sface_2021dec.onnx)

## Быстрый старт

```bash
python cli.py init      # создать базу данных
python cli.py seed      # загрузить демо-набор лиц из faces_data
python cli.py serve     # запустить веб-интерфейс
python cli.py camera    # режим живой камеры (окно OpenCV)
```

Веб-интерфейс открыть в браузере: <http://127.0.0.1:8000>

## Режим живой камеры

```bash
python cli.py camera                       # камера по умолчанию
python cli.py camera --index 1 --mode black_list
```

Открывается окно с видео-потоком веб-камеры. Для каждого лица в кадре
рисуется рамка, имя, процент совпадения и решение:

- **зелёная рамка** + `ACCESS GRANTED` — доступ разрешён;
- **красная рамка** + `ACCESS DENIED` — доступ запрещён.

Управление в окне:

| Клавиша | Действие |
|---------|----------|
| `S` | снимок текущего кадра — запись проверки в журнал (БД + файл) |
| `M` | переключить режим white_list / black_list |
| `Q` / `Esc` | выход |

## Веб-интерфейс

Одна страница, на которой можно:

- проверить изображение (выбрать из набора или загрузить файл) — увидеть
  процент совпадения, решение и причину;
- добавить новое лицо в любую группу;
- исключить лицо из группы «Свой» / сменить группу / статус;
- переключить режим **white_list / black_list** и изменить порог;
- посмотреть журнал проверок.

## Командный интерфейс

```bash
python cli.py enroll "Иван Иванов" path/to/face.jpg          # добавить «своего»
python cli.py enroll "Злодей" path/to/face.jpg --group "Чёрный список"
python cli.py list                                           # список лиц
python cli.py remove 5                                       # исключить из «Свой»
python cli.py move 5 --group "Чёрный список"                 # сменить группу
python cli.py status 5 removed                               # исключить из системы
python cli.py check path/to/test.jpg --mode white_list       # проверить изображение
python cli.py mode white_list                                # режим по умолчанию
python cli.py threshold 0.4                                  # порог совпадения
python cli.py log                                            # журнал проверок
```

## Демо-сценарии заказчика

После `python cli.py seed` готовы все три сценария:

1. **Разрешённый пользователь** — проверить лицо из группы «Свой»
   (например, `faces_data/face/maria_bolt/1.webp`) → `ДОСТУП РАЗРЕШЁН`.
2. **Исключение из доступа** — `python cli.py remove <id>` для «своего»,
   затем повторная проверка того же лица → `ДОСТУП ЗАПРЕЩЁН`.
3. **Запрет и unknown**:
   - лицо из чёрного списка (`faces_data/face/gleb_garman/1.webp`) → отказ;
   - лицо `ulyana_salomonova` (нет в базе) → unknown, отказ.

## Алгоритм работы

1. На изображении детектируется лицо (YuNet). Если лица нет — отказ.
2. Лицо выравнивается и переводится в 128-мерный эмбеддинг (SFace).
3. Эмбеддинг сравнивается со всеми признаками активных лиц в БД,
   ищется максимальная косинусная близость → **процент совпадения**.
4. Принятие решения:
   - совпадение с лицом из **чёрного списка** выше порога → **отказ** (всегда);
   - режим **white_list** — допуск только «своих» выше порога;
   - режим **black_list** — блокируется только чёрный список,
     остальные распознанные лица допускаются;
   - совпадение ниже порога → **unknown**, отказ.
5. Событие записывается в таблицу `checks` и в `logs/checks.log`.
